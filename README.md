## 🚀 Asosiy Imkoniyatlar (Key Features)

1. **🧭 Qiziqish va qobiliyatga qarab AI kasb yo‘naltiruvchi (Career Quiz & Profiler)**
   - 6 bosqichli qiziqarli va interaktiv test.
   - Google Gemini AI orqali natijalarni chuqur tahlil qilish, eng mos IT mutaxassisligini aniqlash, oylik maosh darajasi va ilk 3 ta qadamni ko'rsatish.

2. **🗺️ AI va IT bo‘yicha individual ta'lim rejasi (Personalized Learning Roadmap)**
   - Tanlangan soha (Sun'iy Intellekt, Frontend, Backend, Mobil, Kiberxavfsizlik), bilim darajasi va haftalik bo'sh vaqtga moslashtirilgan 4 haftalik yo'l xaritasi.
   - Bajarilgan vazifalarni belgilash (Progress Tracker) va interaktiv foiz hisoblagich.
   - Bepul o'zbek va xalqaro o'quv resurslari tavsiyalari.

3. **💡 Mini-loyihalar yaratish uchun AI mentor & Kod Ustaxonasi (Project Studio)**
   - *Women in Tech* yo'nalishidagi 4+ tayyor mini-loyiha g'oyalari (Ayollar salomatligi ilovasi, Smart Byudjet, EcoGirl AI tasniflagich, Portfolio veb-sayti).
   - O'zbek tilida gapiruvchi samimiy, do'stona va bilimdon **DigiHer Mentor** (AI Ustoz).
   - Brauzer ichidagi **Live Code Playground** (kod muharriri, jonli natija va sun'iy intellekt orqali kodni tekshirish).

4. **🎓 Tanlovlar, grantlar va imkoniyatlar portali (Opportunities & Grants Hub)**
   - Nufuzli xalqaro va milliy grantlar (Technovation Girls, Google Women Techmakers, Girls in AI Hackathon, Grace Hopper Celebration, IT-Park grantlari).
   - Qidiruv va toifalar bo'yicha filtrlash.
   - **AI Yordamida Motivatsion Xat (SOP/Cover Letter) Yozish**: Ariza topshirish uchun tayyor, ta'sirchan motivatsion xat generatori.

5. **💾 Supabase & LocalStorage gibrid ma'lumotlar boshqaruvi**
   - Foydalanuvchi ma'lumotlari, test natijalari, o'quv rejalari va saqlangan grantlarni bulutli Supabase PostgreSQL bazasida yoki brauzer xotirasida saqlash.

## 🛠 Texnologiyalar To'plami (Tech Stack)

- **Frontend**: HTML5, Modern JavaScript (ES6+), Tailwind CSS, Lucide Icons, Marked.js, Canvas Confetti.
- **Sun'iy Intellekt**: Google Gemini API (`gemini-flash-latest`, `gemini-3.5-flash-lite`, `gemini-3.8-flash`).
- **Ma'lumotlar Bazasi**: [Supabase](https://supabase.com) (PostgreSQL, Row Level Security, REST API) + LocalStorage fallback.
- **Deployment**: [Vercel](https://vercel.com) (Zero-config Edge Deployment, SPA Routing) & [GitHub](https://github.com/nozaninabduganiyeva4-eng/digiher-ai).

## ⚡ Vercel-ga 1 Bosqichda Joylash (Deploy to Vercel)

Loyiha Vercel platformasi uchun to'liq sozlangan:

1. Yuqoridagi **"Deploy with Vercel"** tugmasini bosing yoki [vercel.com/new](https://vercel.com/new) manziliga kiring.
2. `https://github.com/nozaninabduganiyeva4-eng/digiher-ai` omborini tanlang.
3. Deploy tugmasini bosing. Loyiha 30 soniyada butun dunyo bo'ylab jonli (live) efirga chiqadi!

---

## 🗄 Supabase Ma'lumotlar Bazasini Sozlash

1. [supabase.com](https://supabase.com) saytida yangi bepul loyiha (Project) oching.
2. Supabase panelidagi **SQL Editor** bo'limiga kiring.
3. Loyihadagi [`supabase/schema.sql`](supabase/schema.sql) faylining to'liq matnini nusxalab, SQL Editor-ga joylang va **Run** tugmasini bosing.
4. Supabase **Settings -> API** bo'limidan `Project URL` va `anon public key` kalitlarini oling.
5. DigiHer AI veb-saytidagi **Sozlamalar (⚙️)** tugmasini bosib, ushbu ma'lumotlarni kiriting.

## 💻 Mahalliy Kompyuterda Ishga Tushirish (Local Run)

Loyiha hech qanday og'ir modullarsiz ishlaydi. Istalgan lokal server yordamida ochishingiz mumkin:

```bash
# Python yordamida:
python -m http.server 3000

# Yoki Node.js yordamida:
npx serve .
```

Brauzeringizda oching: `http://localhost:3000`
